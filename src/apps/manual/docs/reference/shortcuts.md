# Keyboard shortcuts

Phyllo is keyboard-first: almost every command has a key, and the menu bar and the keys run the same actions. On Windows and Linux, read <kbd>Ctrl</kbd> wherever this page says <kbd>⌘</kbd>.

::: tip Shortcuts stay out of your way while you type
Single-key shortcuts (Space, M, S…) never fire while a text field or code editor has focus. Press <kbd>Esc</kbd> or click an empty part of the window first. The <kbd>⌘</kbd> shortcuts for views, saving and settings still work from text fields, but not from inside a code editor.
:::

You can also see the full list inside the app under **Settings › Shortcuts**.

## Playback

| Keys | Action | Where |
| --- | --- | --- |
| <kbd>Space</kbd> | Play / pause | Arrange, Pattern, Mixer |
| <kbd>⏎</kbd> | Stop and return to the start | When focus is on the transport buttons |
| <kbd>L</kbd> | Loop on / off | Arrange, Pattern, Mixer |
| <kbd>R</kbd> | Arm MIDI recording | Arrange, Pattern, Mixer |

## Tracks and tools

| Keys | Action | Where |
| --- | --- | --- |
| <kbd>M</kbd> | Mute the selected track | Arrange, Pattern, Mixer |
| <kbd>S</kbd> | Solo the selected track | Everywhere except Pro Arrange, where it's the Split tool |
| <kbd>V</kbd> | Select tool | Pro, Arrange |
| <kbd>B</kbd> | Draw tool | Pro, Arrange |
| <kbd>S</kbd> | Split tool | Pro, Arrange |
| <kbd>⌘</kbd> <kbd>K</kbd> | Search sounds; <kbd>⏎</kbd> inserts the result onto the selected track | Arrange, Pattern, Mixer |
| <kbd>↑</kbd> / <kbd>↓</kbd> | Select the previous / next track | Focus on a track header |

## On the timeline

| Keys or gesture | Action |
| --- | --- |
| <kbd>←</kbd> / <kbd>→</kbd> | Move the focused clip by one snap step |
| <kbd>⇧</kbd> <kbd>←</kbd> / <kbd>⇧</kbd> <kbd>→</kbd> | Shorten or lengthen the focused clip |
| <kbd>Delete</kbd> or <kbd>⌫</kbd> | Remove the focused clip |
| <kbd>⏎</kbd> | Open the focused clip's track in the Pattern editor |
| <kbd>⌥</kbd>-drag a clip | Duplicate it |
| <kbd>⇧</kbd>-drag on the ruler | Draw a loop region |
| Click a section chip | Jump to that section |
| <kbd>⌥</kbd>-click a section chip | Loop that section |
| <kbd>⌥</kbd>-click a track's **S** | Solo that track only, un-soloing the others |
| <kbd>⌘</kbd>-click a track's **M** | Mute every other track; again to unmute them all |
| <kbd>⇧</kbd> while dropping a sound | Add it as a layer on the track instead of a new track |

| <kbd>⇧</kbd> <kbd>⌘</kbd> <kbd>G</kbd> | Switch between Guided and Pro |
| <kbd>⌘</kbd> <kbd>,</kbd> | Settings |

## Files and editing

| Keys | Action |
| --- | --- |
| <kbd>⌘</kbd> <kbd>N</kbd> | New groove |
| <kbd>⌘</kbd> <kbd>O</kbd> | Open… |
| <kbd>⌘</kbd> <kbd>S</kbd> | Save |

## In dialogs and fields

| Keys | Action |
| --- | --- |
| <kbd>Esc</kbd> | Close a dialog, menu or popover; cancel a rename or a typed knob value |
| <kbd>⏎</kbd> | Confirm a rename or a typed value |
| <kbd>F2</kbd> | Rename the track in the inspector header |
| <kbd>↑</kbd> / <kbd>↓</kbd> in the tempo field | Tempo ±1 BPM; hold <kbd>⇧</kbd> for ±10 |
| <kbd>←</kbd> / <kbd>→</kbd> on a panel's resize handle | Resize the library or inspector panel; <kbd>Home</kbd> / <kbd>End</kbd> jump to the narrowest or widest |
